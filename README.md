# Muhammed Minhaj — Portfolio

A dark, editorial-style Odoo/Python developer portfolio inspired by the supplied reference.

## Files
- `index.html` — page content
- `styles.css` — responsive design
- `script.js` — scroll-reveal and mobile navigation
- `assets/project-demo.mp4` — supplied demo video used in the AI Time Tracking project

## Before publishing
Replace these placeholders in `index.html`:
- `your.email@example.com`
- LinkedIn URL
- GitHub URL

You can also change project descriptions, experience dates, and skills.

## Free GitHub Pages hosting
1. Create a GitHub repository, e.g. `minhaj-portfolio`.
2. Upload all files/folders from this project.
3. In GitHub: Settings → Pages → Deploy from branch → `main` → `/root`.
4. GitHub will provide a free `https://YOUR-USERNAME.github.io/minhaj-portfolio/` address.
